# えいご きいて えらぼう！

小学校低学年向けの英会話アプリです。
英語の音声を聞いて、合う絵（絵文字）を4つの中から選びます。

`index.html` の1ファイルだけで動きます。インストールやサーバーは要りません。

## つかいかた

1. `index.html` をブラウザ（Chrome / Safari / Edge）で開きます。
2. テーマを選ぶと、英語の読み上げが始まります。
3. 🔊 ボタンを押すと、何度でも聞き直せます。
4. 合う絵を選びます。1回10問で、最後に点数が出ます。

## できること

- **英語の読み上げ**：ブラウザの読み上げ機能（Web Speech API）を使います。
- **英語とひらがな**：英語の文字はいつも表示されます。ひらがなの意味は、答えたあとに出ます。
- **正解したとき**：花丸が出て、「ピンポン」と鳴ったあとに「Great!」の声が出ます。1.5秒で次の問題に進みます。
- **まちがえたとき**：正解に ⭕ がつき、「ブブー」と鳴ったあとに、もう一度読み上げます。3秒で次の問題に進みます。
- 効果音はブラウザで作っているので、音声ファイルは不要です。iPhone では消音モード（マナーモード）だと効果音が鳴りません。
  「つぎへ」ボタンを押せば、待たずに進めます。
- **結果画面**：10問中の点数と ⭐（3つまで）が出ます。
- **画面**：大きな文字・大きなボタン・明るい色です。パソコンではスクロールなしで1画面に収まります（トップ画面は左にテーマ、右にカレンダー）。
  スマホでも使えます。スマホのトップ画面では、カレンダーはテーマの下にあり、スクロールすると見られます。

## カレンダー

トップ画面にカレンダーがあります（けいさんアプリと同じしくみ・見た目です）。

- その日に答えた問題の数を記録します。何回かに分けて解いても合計します。
- 1日に **10問以上** で ○、**20問以上** で花丸がつきます。
- 今日の日付はオレンジの枠で目立たせています。
- ◀ ▶ で前の月・次の月に切り替えられます。日付を押すと、その日の問題数が出ます。
- 記録はブラウザに保存されるので、閉じても消えません。
  けいさんアプリとは別の名前（`eigo-kiite-records`）で保存するので、数は別々です。

## テーマ（12こ ＋ ぜんぶ）

| 🐶 どうぶつ | dog, cat, elephant |
| 🍎 くだもの | apple, banana, strawberry |
| 🎨 いろ | red, blue, yellow |
| 🔢 かず | one 〜 ten |
| 🥕 やさい | carrot, tomato, potato |
| 🍔 たべもの | rice, pizza, ice cream |
| 🚗 のりもの | car, train, airplane |
| 👀 からだ | eye, ear, hand |

## こえの せってい（⚙️）

スタート画面右上の ⚙️ から開きます。

- **おまかせ（初期設定）**：アメリカ英語（en-US）の声の中から、いちばん自然な声を自動で選びます。
  優先順は Natural（Edge）→ Neural → Google（Chrome）→ Premium / Enhanced（Mac・iPhone）です。
- **声を選ぶ**：一覧から好きな声を選べます。★ は自然な声のしるしです。選ぶとお試しで読み上げます。
- **はやさ**：🐢 ゆっくり / 🚶 ふつう / 🐇 はやい
- 設定はブラウザに保存されます。

もっと自然な声にしたいとき：

- **Edge** で開くと、とても自然な声（Microsoft … Online (Natural)）が使えます。
- **Mac / iPhone** では、設定のアクセシビリティ →「読み上げコンテンツ」で「Ava（プレミアム）」などをダウンロードすると、自動で選ばれます。

## ことばの追加・変更

`index.html` の `<script>` の中にある `THEMES` を編集します。1語は1行です。

```js
{ en: "dog", ja: "いぬ", pic: "🐶" },
```

- 1つのテーマに **4語以上** 入れてください（選択肢が4つのため）。
- 10語より少ないテーマでは、同じことばが2回出ることがあります。
- 同じテーマの中で、同じ絵文字を使わないでください。

## 動作環境

- Chrome / Safari / Edge の最新版（パソコン・スマホ・タブレット）
- 読み上げの声は、使う端末やブラウザによって変わります。
- 音が出ないときは、音量とマナーモード（消音）を確認してください。
